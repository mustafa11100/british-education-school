# EduCore Platform — Full Stack

منصة متخصصة بإدارة المدارس والمؤسسات التعليمية متعددة المؤسسات.

## التشغيل على جهازك
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   `npm install`
4. ثم:
   `npm start`
5. افتح المنصة محلياً حسب المنفذ المعرّف في البيئة.

## الهوية
- اسم المنصة: **EduCore Platform**
- إنتاج وتطوير: **مصطفى عادل الحاج زيدان**
- هوية كل مدرسة قابلة للتخصيص دون تغيير هوية المنصة الأساسية.

## قبل الاستخدام الحقيقي
- تفعيل HTTPS.
- ضبط SMTP لاستعادة كلمات المرور والتنبيهات البريدية.
- مراجعة إعدادات النسخ الاحتياطي والاستعادة.
- تفعيل إعدادات الأمان المناسبة لبيئة الإنتاج.
