# مدرسة التعليم البريطاني — Full Stack

## التشغيل على جهازك
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   `npm install`
4. ثم:
   `npm start`
5. افتح:
   `http://localhost:3000`
