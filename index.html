تسجيل مستخدم جديد

اكتب اسمك الحقيقي واختر مهنتك. سنولّد لك اسم مستخدم خاصًا بك، ويُفتح حسابك بعد اعتماد الإدارة.

لن تحتاج إلى كتابة User مثل Admin أو Teacher. اسم المستخدم الخاص بك يُنشأ تلقائيًا من اسمك ومهنتك.

تسجيل مدرسة أو منشأة تعليمية

اسم المدرسة سيكون هو هوية الدخول للمدير. لا نُنشئ للمدير اسم Admin منفصل.

بعد اعتماد المدرسة، يدخل المدير باسم مستخدم المدرسة الذي سيظهر لك بعد إرسال الطلب.

استعادة كلمة المرور

أدخل بريدك الإلكتروني وسنرسل تعليمات الاستعادة إذا كان الحساب مسجلاً.
